# SpeakMate · Demo 录屏脚本

目标时长 **5–8 分钟**。原则:**全程真实操作、真实接口返回,不剪辑伪造**;任何走降级/Mock 的地方口播说明(对应评分「不造假演示」)。

录制前准备:
- `cp .env.example .env` 填好 MiniMax / Azure(可选百炼)Key,或在设置页配置;
- `python app.py`,**用 Chrome** 打开 http://127.0.0.1:5001,允许麦克风;
- 准备好几句要说的英文(含一句故意有错的,用来演示纠错)。

---

## 分镜与口播

### ① 开场(约 0:30)
- **画面**:首页(`01-scenarios`),右上角状态「对话 在线 · 发音评测 在线」。
- **口播**:「这是 SpeakMate,一个 AI 英语口语陪练。它解决的不是『背单词』,而是『知道但不敢说、不会说』——让你在真实场景里开口练,并给出可量化的反馈。右上角能看到对话和发音评测都是在线真实接入。」

### ② 选场景 + 难度(约 0:30)
- **画面**:点「求职面试」卡片高亮,拖动难度到 L2。
- **口播**:「支持面试、点餐等场景,新增场景只是加一份配置。难度 L1–L5 控制 AI 的用词和语速。我选面试、日常难度,开始训练。」

### ③ 实时语音对话(约 1:30)——核心:自然度 + 延迟
- **画面**:AI 开场白出现并**自动朗读**;按住「按住说话」说第一句(如「I have been to Paris.」),松开;AI **流式**回复并朗读。
- **口播**:「AI 用 MiniMax 流式输出,前端按句切分、首句一凑满就送 TTS 播放(首句优先)。实测首句可听约 1~2 秒(随网络/模型负载波动,见 docs/QoS.md)。它全程在面试官角色里;我故意答偏一点,它会自然地把话题拉回来——交互是连贯的,不是一问一答的机器人。」
- **提示**:展示一次「答偏→被拉回」体现对话自然度。

### ④ 发音评测(约 1:00)——核心:真音素级
- **画面**:用户气泡下方弹出发音卡片(`02-conversation`):总分 + 发音/流利/韵律/完整四维。
- **口播**:「发音评测用的是 Azure 的音素级方案——它真的『听』了我的录音,给出准确度、流利度、韵律、完整度,还能精确到每个单词。这是真实声学分析,不是让大模型看文字猜分。短句语调平,韵律分就偏低,说明它是真能区分的。」

### ⑤ 语法 / 表达纠错(约 1:00)——核心:精准 + 时机
- **画面**:说一句有错的(如「I has went there yesterday and I very like it.」),下方弹出「表达优化」卡片:逐条「错误→原因→建议」+ 整句润色。
- **口播**:「纠错是『延迟纠错』——不在我说话中途打断,等我说完再给。它指出主谓一致、时态、用词三处问题,并给出地道的整句改写。这样既不破坏对话流畅,又能精准纠错。」

### ⑥ 课后总结 + 六维(约 0:40)
- **画面**:点「结束 · 课后总结」,展示优秀表达 / 高频错误 / 推荐表达 / 训练建议 + 六维条形。
- **口播**:「一次训练结束,自动生成课后总结:亮点、高频错误、推荐表达和下一步建议;同时更新六维能力画像。」

### ⑦ Dashboard 成长(约 0:50)——核心:可量化反馈
- **画面**:进入 Dashboard(`03-dashboard`):练习次数 / 时长 / 打卡 / 覆盖,六维雷达、成长曲线、场景覆盖率、错误分布。
- **口播**:「所有数据落 SQLite 持久化。Dashboard 用六维雷达看能力结构,用成长曲线看综合分趋势,还能看场景覆盖和高频错误类型——把『有没有进步』变成看得见的数据。注意发音、流利两维来自 Azure 的真实评分,没有数据时我们宁可留空,也不编分。」

### ⑧ 配置自己的 Key(约 0:40)
- **画面**:设置页(`04-settings`),Key 打码显示;点「测试连接」,三家返回结果。
- **口播**:「用户可以在设置页填自己的 Key,保存即热生效、无需重启;Key 只存在本地、回显打码、绝不入库。还能一键『测试连接』真实验证。」

### ⑨ 跨浏览器兜底(约 0:30,可选)
- **画面**:Chrome 勾「用百炼识别」,或换 Safari 打开。
- **口播**:「ASR 默认用浏览器本地识别(零延迟);Safari/Firefox 不支持时,自动走服务端百炼 Paraformer 兜底,Chrome 也能手动切——跨浏览器都能用。」

### ⑩ 技术架构 + 收尾(约 0:30)
- **口播**:「架构上,所有模型访问收敛在一个 `AIService` 入口,任何外部失败都自动降级、不让应用崩;代码有 59 个测试、核心模块覆盖率 90% 以上,git 历史是一个个独立可 review 的 PR。诚实是底线——做不到的维度留空,走降级都会标注。谢谢观看。」

## 录制清单(逐条对应评分点)
- [ ] 场景选择 + 难度 → 产品设计/完整度
- [ ] 实时语音、首句低延迟、AI 自然拉回 → 交互自然度 + 端到端延迟
- [ ] 发音四维 + 逐词 → 评测精准度(真音素级)
- [ ] 延迟纠错三段式 → 纠错精准度 + 时机
- [ ] 课后总结 + 六维 + Dashboard → 可量化反馈
- [ ] 设置页 Key 打码 + 测试连接 → 工程/安全
- [ ] 百炼兜底 → 健壮性/跨浏览器
- [ ] 一句话技术架构 + 测试/PR → 开发质量
